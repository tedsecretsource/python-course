# Overview

Jupyter Notebooks are interactive documents that allow you to combine code, text, interactive elements (forms) and visualizations in a single document. This is commonly used in the ML/AI community to experiment with code and share results.

Notebooks are json files with the extension `.ipynb`. They can be "executed" in a Jupyter environment, which can be a local installation or a cloud-based service like Google Colab. In theory, VS Code supports running notebooks, but I have been unable to get this to work. Instead, use a [Google Colab to experiment with Jupyter Notebooks](https://colab.research.google.com/).
